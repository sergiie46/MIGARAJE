# Mi Garaje

Proyecto Android Studio de **Mi Garaje**.

## Abrir

1. Descomprime el ZIP en una carpeta nueva.
2. Abre esa carpeta raíz con Android Studio (la que contiene `settings.gradle`).
3. Espera a que termine Gradle Sync.
4. Pulsa Run ▶ para ejecutar la build debug.

El proyecto incluye Gradle Wrapper 9.6.0 y configuración para Java 17. Android Studio descargará las dependencias/SDK que falten.

Para activar Firebase/Google Sign-In, AdMob de producción, Play Billing real y firma release consulta `CONFIGURAR_MI_GARAJE.md`.
